## About the Project

SmartSpace is an intelligent web-based interior design platform that helps users furnish their living spaces based on room dimensions, personal style, color preferences, and budget.

The platform combines image analysis, personalized furniture recommendations, budget optimization, and interactive 2D visualization to simplify the entire furnishing experience.

## Key Features

- **Room Analysis:** Extract dominant colors and estimate interior design style from uploaded room images.
- **Personalized Recommendations:** Match furniture with room dimensions, style, and color preferences.
- **Budget Optimization:** Recommend suitable furniture within the user's budget in SAR.
- **Interactive 2D Layout:** Visualize and rearrange furniture with automatic fit and collision checks.
- **Smart Alternatives:** Suggest alternative products based on available space and budget.
- **Multi-Store Matching:** Match recommended items across sample furniture catalogs.
- **Design Management:** Save designs and export shopping lists.
- **Order Management:** Simulate checkout, store orders, and delivery tracking.
- **Admin Dashboard:** Manage furniture catalogs and store data sources.

| JSON & CSV | Catalog data management and export |

## How It Works

1. Upload a room photo.
2. Enter room dimensions and room type.
3. Select preferred style, colors, and budget.
4. Generate personalized furniture recommendations.
5. Explore and customize the interactive 2D layout.
6. Save the design and export the shopping list.
7. Simulate checkout and track store orders.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/aseel-aihub/SmartSpace.git
```

Open `index.html` in your browser.

No backend server, API key, or package installation is required.

## Project Status

SmartSpace is currently an interactive graduation project prototype.

The current version uses client-side image analysis, heuristic algorithms, and rule-based recommendations. Deep learning models, live retailer integration, secure backend services, and real payment processing are planned for future development.

All products, stores, prices, and transactions are simulated for demonstration purposes.
