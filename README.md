# SmartSpace — Prototype

Static web prototype of SmartSpace (IS GP1, IMSIU). Open `index.html` in a browser.

The screens follow the To-Be business process: sign in → room photo, dimensions and type →
style, colors and exact budget → analysis, recommendations, store matching, 2D layout and checks →
review (approve, request suggested alternatives, or exit) → shopping list and store links.
The Admin view covers "Manage Furniture Catalog" and "Store Data Sources".

All stores, products, prices and links are fictional demo data. Sign-in and saved designs are
stored in the browser only (localStorage).
