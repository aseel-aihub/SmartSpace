# SmartSpace — Prototype

Static web prototype of SmartSpace (IS GP1, IMSIU). Open `index.html` in a browser.

The screens follow the To-Be business process: sign in → room photo, dimensions and type →
style, colors and exact budget → analysis, recommendations, store matching, 2D layout and checks →
review (approve, request suggested alternatives, or exit) → checkout and payment through SmartSpace →
order sent to the stores → store confirms, marks items unavailable, or delivers → order tracking.
The Admin view covers "Manage Furniture Catalog" and "Store Data Sources". The Store portal is used by
the furniture stores to manage the orders that SmartSpace sends to them.

All stores, products and prices are fictional demo data. Checkout is simulated: no real payment is
made and card details are never stored. Sign-in and saved designs are
stored in the browser only (localStorage).
